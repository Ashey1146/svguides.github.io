How to Add More Buttons & Link GitHub Pages

Quick step-by-step guide to edit this HTML code

1. Copy a Card Block

Open this HTML file in any editor (VS Code, Notepad, etc.). Find the section marked <main id="guidesGrid"> and duplicate one of the <a href="..." class="guide-card..."> tags.

2. Change the GitHub Page Link

Change the href="..." attribute to point to your new GitHub HTML page:

href="https://YOUR-USERNAME.github.io/YOUR-REPO/your-new-guide.html"

Or if hosted in the same repository folder, use relative links like: href="your-new-guide.html"

3. Customize Text & Category

  • Change data-category="handbooks" (Options: handbooks, rules, assets, departments).
  • Update Title, Icon name, and Description text inside the copied card.
